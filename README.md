# SafePlate web pages

The source of https://fulmen123.github.io: SafePlate's home page, privacy policy and terms of use. These are
plain HTML pages, served by GitHub Pages from `main`. The app's code is not in this project.

- `index.html`: the home page (Google's sign-in Branding page links to it)
- `privacy.html`: the privacy policy (Google Branding, App Store Connect, and the app)
- `terms.html`: the terms of use

When you change a promise in `privacy.html` or `terms.html`, update its "Last updated" date.
